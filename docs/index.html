Como foi feito

  1. Baixar. Dois arquivos do Portal de Dados Abertos do TSE (Resultados 2026): votacao_secao_2026_BR, com os votos de cada candidato em cada seção, e detalhe_votacao_secao_2026, com aptos, comparecimento e horário de cada seção. CSV com separador ; e codificação latin-1.
  2. Juntar. O script lê os zips em streaming, sem descompactar no disco, e junta os dois arquivos pela chave estado + município + zona + seção. Sai uma linha por urna.
  3. Ordenar no tempo. Cada seção tem o horário em que o boletim de urna chegou ao TSE (DT_RECEBIMENTO_BU_HOR_TSE, horário de Brasília). Ordenando as urnas por esse horário e somando os votos, dá para refazer a apuração minuto a minuto.
  4. Analisar. Com os acumulados saem a virada, o maior pico de vantagem de cada lado, a janela de 10 minutos com maior arrancada e o momento em que a vantagem passou dos eleitores das urnas que faltavam.
  5. Mostrar. O resultado vira JSON pequeno que esta página lê. O código e o passo a passo estão no repositório.

Dados: Tribunal Superior Eleitoral (boletins de urna). Mapa: IBGE. Horários de Brasília.
